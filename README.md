## Завдання А (Алгоритмічне опрацювання числових списків)

Створити список дійсних чисел. Вставити перший додатний елемент списку після кожного від’ємного числа.

### Код

```cpp
#pragma once
#include <forward_list>

	private: System::Void button1_Click(System::Object^ sender, System::EventArgs^ e) {
		// 1. Створюємо список дійсних чисел
		std::forward_list<double> list = { -4.2, 3.5, -8.0, 1.2, -6.4 };

		// Виводимо початковий список у listBox1
		listBox1->Items->Clear();
		for (double x : list) {
			listBox1->Items->Add(x.ToString());
		}

		// 2. Знаходимо перший додатний елемент списку
		double firstPositive = 0.0;
		bool foundPositive = false;
		for (double x : list) {
			if (x > 0) {
				firstPositive = x;
				foundPositive = true;
				break;
			}
		}

		// 3. Якщо додатний елемент існує, вставляємо його після кожного від'ємного
		if (foundPositive) {
			for (auto it = list.begin(); it != list.end(); ++it) {
				if (*it < 0) {
					// insert_after повертає ітератор на щойно вставлений елемент,
					// тому цикл коректно перейде до наступного елемента на наступній ітерації
					it = list.insert_after(it, firstPositive);
				}
			}
		}

		// 4. Виводимо оновлений список у listBox2
		listBox2->Items->Clear();
		for (double x : list) {
			listBox2->Items->Add(x.ToString());
		}
	}
```

### Програма для Завдання А (Вставка елемента за умовою)

* **Призначення:** модифікація списку дійсних чисел шляхом дублювання першого додатного числа після кожного від’ємного.
* **Принцип роботи:**
1. Ініціалізується однозв'язний список `std::forward_list<double>` та виводиться у перший візуальний список (`listBox1`).
2. Програма проходить циклом по списку та запам'ятовує перше зустрінуте число, більше за нуль (`x > 0`), після чого одразу перериває пошук (`break`).
3. За допомогою ітераторів здійснюється повторний прохід списком: щоразу, коли поточний елемент виявляється від'ємним (`*it < 0`), метод `insert_after()` вставляє знайдене додатне число одразу після нього. При цьому ітератор зміщується на вставлений елемент, щоб уникнути його повторної перевірки.
4. Оновлений список виводиться у другий візуальний компонент (`listBox2`).

## Завдання Б (Прикладні задачі).

Швидкість руху. Створити список швидкостей авто. Знайти максимальну, мінімальну та середню швидкість.

### Код

```cpp
#pragma once
#include <forward_list>

private: System::Void button2_Click(System::Object^ sender, System::EventArgs^ e) {
	// 1. Створюємо список швидкостей автомобіля (км/год)
	std::forward_list<double> speeds = { 60.5, 85.0, 42.0, 110.5, 72.0 };

	// Виводимо список у listBox3
	listBox3->Items->Clear();
	for (double s : speeds) {
		listBox3->Items->Add(s.ToString());
	}

	// 2. Перевіряємо, чи список не порожній, та обчислюємо показники
	if (!speeds.empty()) {
		double maxSpeed = speeds.front();
		double minSpeed = speeds.front();
		double sum = 0.0;
		int count = 0;

		for (double s : speeds) {
			if (s > maxSpeed) {
				maxSpeed = s;
			}
			if (s < minSpeed) {
				minSpeed = s;
			}
			sum += s;
			count++;
		}

		double avgSpeed = sum / count;

		// 3. Виводимо результати у label1
		label1->Text = "Максимальна швидкість: " + maxSpeed.ToString() + " км/год\n" +
			"Мінімальна швидкість: " + minSpeed.ToString() + " км/год\n" +
			"Середня швидкість: " + Math::Round(avgSpeed, 2).ToString() + " км/год";
	}
}
```

### Програма для Завдання Б («Швидкість руху»)

* **Призначення:** статистичний аналіз даних про швидкість автомобіля (пошук максимуму, мінімуму та середнього значення).
* **Принцип роботи:**
1. Створюється список швидкостей `std::forward_list<double>`, який відображається в елементі `listBox3`.
2. Початковими значеннями для максимальної та мінімальної швидкості встановлюється перший елемент списку (`speeds.front()`), а лічильники суми та кількості обнуляються.
3. У циклі програма послідовно порівнює кожну швидкість із поточними максимумом і мінімумом (оновлюючи їх за потреби), додає значення до загальної суми та збільшує лічильник елементів.
4. Середня швидкість обчислюється діленням загальної суми на кількість елементів (`sum / count`), після чого всі три показники форматуються та виводяться у текстову мітку `label1`.
